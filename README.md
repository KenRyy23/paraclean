# ParaClean – San Jose Heights Executive Subdivision

Garbage collection schedule, reminders, live truck status and waste guide
for the residents of **San Jose Heights Executive Subdivision, Antipolo City**.

## Download (Android)

**[Download ParaClean.apk](https://github.com/KenRyy23/paraclean/raw/main/ParaClean.apk)**

1. Tap the link above and download the file.
2. Open the downloaded file. If asked, allow **"Install unknown apps"** for your browser.
3. Tap **Install**, then **Open**, and sign up with your Block and Lot.

### Paano i-install
1. I-tap ang link sa itaas para ma-download ang file.
2. Buksan ang na-download na file. Kapag tinanong, payagan ang **"Install unknown apps"**.
3. I-tap ang **Install**, tapos **Open**, at mag-sign up gamit ang inyong Block at Lot.

Questions? Please contact the SJHES HOA office.
